Dataset & experimental protocol

Data. CoRE MOF 2019 (v2.0.1, Zenodo), CIF files, computation-ready set with all solvent removed. Atoms are vertices, edges are internal interatomic distances (rotation/translation invariant), unary cost = feature distance (covalent radius, atomic mass) + 50 per element mismatch.

Planted ground truth. For each MOF, the target graph H is the N atoms nearest a random metal centre; the query G is the L nearest atoms with Gaussian coordinate noise plus M−L outlier atoms from the shell just beyond H, with random relabelling. The true correspondence is known by construction. This is a planted benchmark on real atomic geometry, not an independently annotated matching task.

Methods. Fast-WCS single-start, Fast-WCS multi-start (10 restarts unless noted), RLX1F (our re-implementation, not the original authors’ code), SciPy FAQ, feature-only Hungarian. Intervals are 95% bootstrap CIs over MOFs.

1. 2D matching benchmark (Phase 1)

More restarts help, with diminishing returns

Multi-start accuracy on the noise sweep with 10 vs 30 restarts (same 100 MOFs, same instances). Mean accuracy rises from 69.1% to 75.7% over 500 paired instances (paired Wilcoxon p = 6.8×10−6; instances share MOFs across noise levels, so these pairs are not fully independent). Runtime rises from about 70 ms to about 200 ms.

2. 3D conformer alignment (Phase 2: Kabsch SVD)

Each query conformer is rotated and translated by a random rigid motion, perturbed with σ = 0.05 Å noise, and given 2 outlier atoms. The solver sees only internal distances; matched atoms are superposed with Kabsch and the RMSD is reported. Scenarios: 16, 20 and 24 atoms (60 MOFs each). Success = RMSD < 1.0 Å.

3. Kernel virtual screening (2D / 3D / hybrid)

Library of 300 MOFs, 30 query “actives” (label: pore-limiting diameter in the top 25%). Each MOF is its 30-atom local fragment; MOFs are ranked by kernel similarity to the query. ROC-AUC with 95% bootstrap CI over queries. k2D = exp(−γF*/L), k3D = exp(−γRMSD²), hybrid = (1−β)k2D + βk3D; γ = 1/median over scored pairs; all β values are reported. The task and baseline are our own design.

Limitations (please read)
  • Ground truth is planted (conserved core + noise + outliers); it is not an independent MOF-to-MOF annotation.
  • Multi-start uses 10–30 restarts, i.e. several times the compute of single-start; absolute accuracy saturates well below 100%.
  • Many MOF atoms are symmetry-equivalent, so exact atom-identity accuracy understates geometric correctness; RMSD success rates are the more reliable 3D measure.
  • RLX1F is our re-implementation of the published description. The screening task (PLD label, local fragments, composition baseline) is our own design.
  • In screening, k2D only matches the composition baseline, and k3D and the hybrid give no gain on this task.
