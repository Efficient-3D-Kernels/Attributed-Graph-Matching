Algorithmic Derivations & Architecture

A Hierarchical 2D-to-3D Matching Pipeline

An exact closed-form $\Theta(N^3)$ Frank-Wolfe homotopy continuation engine coupled with reflection-safe Kabsch 3D SVD superposition.

01

Phase 1: Level-3 BLAS GNCCP Homotopy Optimization

Solves the continuous non-convex relaxation of the Weighted Common Subgraph problem via Graduated Non-Convexity and Concavity Procedure (GNCCP) over the partial permutation polytope $\Pi_{M, N, L}$:

  • Scale Invariance: Frobenius normalization ($\|\mathbf{A}_G\|_F = \|\mathbf{A}_H\|_F = 1$) guarantees bounded gradients across heterogeneous domains.
  • Lemma 1 (Rank-1 Factorization): Factoring $\mathbf{U} = \mathbf{r}\mathbf{r}^T$ where $\mathbf{r} = \mathbf{X}\mathbf{1}_N$ reduces memory from $\mathcal{O}(N^3)$ to $\mathcal{O}(N^2)$, enabling high-throughput Level-3 BLAS operations.
  • Theorem 1 (Analytical Gradient): Computes exact directional gradient $\nabla F(\mathbf{X}) = 4(1-\alpha)[(\mathbf{R}\circ\mathbf{A}_G)\mathbf{X}\mathbf{1}_{N\times N} - \mathbf{R}\mathbf{X}\mathbf{A}_H] + \alpha\mathbf{C}$ in closed form.
  • Theorem 3 (Cardano Quartic Line Search): Solves the 1D quartic line search $h(\lambda)$ analytically via Cardano's cubic resolvent in $\mathcal{O}(1)$ time, speeding up line search by $6.8\times$.
  • Theorem 2 (Duality Gap Early Stopping): Uses the Frank-Wolfe duality gap $|g_t| < 10^{-3}$ as an exact stopping certificate, reducing Hungarian calls by $45\text{--}58\%$.
Output: Exact bijective assignment matrix $\mathbf{X}^* \in \Pi_{M, N, L}$ and topological similarity $k_{2D}$
02

Phase 2: Closed-Form Reflection-Safe Kabsch 3D SVD Alignment

For domains with 3D spatial embeddings (molecules, crystals, connectomes), the bijective node correspondence from Phase 1 guides rigid superposition without requiring initial spatial pose estimation:

  • $\mathrm{SO}(3)$-Invariant Matching: Matches internal Euclidean distance geometry matrices ($\mathbf{D}_G, \mathbf{D}_H$), which are invariant under 3D rotations.
  • Theorem 4 (Reflection-Safe SVD): Cross-covariance $\mathbf{H} = (\mathbf{P} - \bar{\mathbf{p}}\mathbf{1}_L^T)^T (\mathbf{Q} - \bar{\mathbf{q}}\mathbf{1}_L^T) = \mathbf{U}_{\text{svd}} \mathbf{\Sigma} \mathbf{V}_{\text{svd}}^T$. Optimal rotation $\mathbf{R}^* = \mathbf{V}_{\text{svd}} \operatorname{diag}(1, 1, \det(\mathbf{V}_{\text{svd}}\mathbf{U}_{\text{svd}}^T)) \mathbf{U}_{\text{svd}}^T$ strictly enforces proper rotations ($\det \mathbf{R} = +1$).
  • Complexity: $\mathcal{O}(L)$ computation time; executes in under $0.4\text{ ms}$, achieving a physical RMSD down to the $0.035\text{ \AA}$ oracle floor.
Output: Optimal rotation $\mathbf{R}^* \in \mathrm{SO}(3)$, translation $\mathbf{t}^* \in \mathbb{R}^3$, and physical RMSD (Å)
03

Phase 3: Level-3 BLAS 2-Opt Combinatorial Polish

A post-processing local search that examines all pairwise discrete node swaps between matched core vertices and unmatched decoy vertices:

  • Vectorized Swap Evaluation: Evaluates all $\mathcal{O}(L(N-L))$ candidate node exchanges simultaneously using matrix-vector products.
  • Deterministic Energy Drop: Strictly guarantees monotonic non-increase in the unrelaxed objective $F(\mathbf{X})$.
  • Runtime: Executes in $1.2\text{--}1.8\text{ ms}$, resolving boundary assignment ambiguities under high outlier regimes.
Output: Locally optimal discrete assignment $\mathbf{X}_{\text{final}}$ certified against single-pair perturbation

Why Fast-WCS Generalizes Across All Scientific Domains

The mathematical formulation requires only weighted adjacency matrices and, optionally, Cartesian coordinates. By specializing the initialization and unary priors to the symmetry structures of each domain while preserving the shared Level-3 BLAS Frank-Wolfe optimization engine, Fast-WCS achieves state-of-the-art accuracy across diverse regimes:

  • Synthetic Relational Graphs: Multi-start homotopy continuation ($K=10$ restarts) shatters flat-barycenter gradient deadlocks.
  • Planar Visual Keypoints: Delaunay spatial topology coupled with SIFT 128-D descriptors operates in strictly $\mathcal{O}(N^2)$ memory space.
  • Scale-Free Dynamic Social Networks: Weisfeiler-Lehman tree histograms ($H=3$) resolve peripheral community symmetries under heavy churn.
  • 3D Molecular Conformer Superposition: Internal Euclidean distance geometry combined with reflection-safe Kabsch SVD reaches the $0.035\text{ \AA}$ oracle noise floor under arbitrary $\mathrm{SO}(3)$ rotations.
