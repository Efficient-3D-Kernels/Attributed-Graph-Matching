Fast-WCS: Analytical Optimization for Structural Correspondence and Partial Matching in Attributed Graphs

We present an exact, closed-form Frank-Wolfe homotopy continuation framework for the $\mathcal{NP}$-hard Weighted Common Subgraph (WCS) problem. By eliminating Lawler tensor memory explosions via a rank-one dyadic factorization ($\mathbf{U} = \mathbf{r}\mathbf{r}^T$), evaluating exact structural gradients in three Level-3 BLAS GEMMs, solving the 1D line search analytically in $\mathcal{O}(1)$ time via Cardano's cubic resolvent, and guaranteeing exact cardinality $L$ through an augmented Burkard Hungarian oracle, Fast-WCS achieves state-of-the-art accuracy across five distinct scientific domains while executing up to $380\times$ faster than competing quadratic solvers in strictly $\mathcal{O}(N^2)$ memory.

Guide: Dr. T Ramraj, Assistant Professor (Sl. Gd), Department of CSE, Amrita Vishwa Vidyapeetham, Coimbatore

Problem Formulation & Classical Bottlenecks

Given two attributed relational graphs $G = (V_G, E_G, \mathbf{A}_G, \mathbf{F}_G)$ and $H = (V_H, E_H, \mathbf{A}_H, \mathbf{F}_H)$ of vertex sizes $|V_G| = M$ and $|V_H| = N$ ($M \le N$), and a target common subgraph size $L \le \min(M, N)$, the Weighted Common Subgraph (WCS) problem seeks an optimal partial permutation matrix $\mathbf{X} \in \mathcal{P}_L$ minimizing structural topological mismatch and unary attribute discrepancy:

$$\min_{\mathbf{X} \in \mathcal{P}_L} F(\mathbf{X}) = \alpha\, f(\mathbf{X}) + (1 - \alpha)\operatorname{tr}(\mathbf{C}^T\mathbf{X})$$

where $\operatorname{tr}(\mathbf{C}^T\mathbf{X}) = \sum_{i=1}^M \sum_{j=1}^N C_{ij} X_{ij}$ measures unary semantic distance, $\alpha \in [0, 1]$ balances topology against node features, and $f(\mathbf{X})$ evaluates structural mismatch via the Frobenius norm:

$$f(\mathbf{X}) = \big\| \mathbf{U} \circ \hat{\mathbf{A}}_G - \mathbf{X}\hat{\mathbf{A}}_H\mathbf{X}^T \big\|_F^2, \quad \text{with } \mathbf{U} = \mathbf{X}\mathbf{1}_{N\times N}\mathbf{X}^T$$

Here $\mathcal{P}_L = \{ \mathbf{X} \in \{0, 1\}^{M \times N} \mid \mathbf{X}\mathbf{1}_N \le \mathbf{1}_M, \; \mathbf{X}^T\mathbf{1}_M \le \mathbf{1}_N, \; \mathbf{1}_M^T\mathbf{X}\mathbf{1}_N = L \}$ represents the discrete partial permutation polytope. WCS is $\mathcal{NP}$-hard, generalizing maximum common subgraph isomorphism and the Quadratic Assignment Problem (QAP).

The Three Fundamental Failure Modes of Prior Continuous Solvers

  1. Lawler Tensor Memory Barrier ($\mathcal{O}(N^4)$): Operating on the 4th-order pairwise affinity tensor $\mathbf{K} \in \mathbb{R}^{MN \times MN}$ (e.g. Spectral Matching, Reweighted Random Walks, Graduated Assignment) requires > 4 GB of RAM at $N = 150$, causing catastrophic out-of-memory crashes on moderate relational structures.
  2. Polynomial Landscape Distortions & Heuristic Truncation: Prior continuous GNCCP relaxations (RLX1, RLX2; Yang et al. 2018) discarded non-linear Hadamard terms and substituted truncated polynomial expansions whose landscape departs from $f(\mathbf{X})$ on the continuous interior $\mathcal{D}_L \setminus \mathcal{P}_L$. Furthermore, their fast variant (RLX1F) solved unconstrained assignments followed by top-$L$ heuristic truncation, violating the exact integer cardinality constraint $\sum_{i,j} X_{ij} = L$.
  3. Automorphic Symmetry Trapping at the Flat Barycenter (Proposition 1): Standard Frank-Wolfe solvers initialize at the flat doubly sub-stochastic barycenter $\mathbf{X}_0 = \frac{L}{MN}\mathbf{1}_{M \times N}$. On regular or automorphic graph topologies, the initial structural gradient is identically constant across all matrix entries: $$\nabla_{\mathbf{X}} f(\mathbf{X}_0) = c \cdot \mathbf{1}_{M \times N}$$ Because every entry is identical, the gradient variance is exactly zero ($\operatorname{Var}(\nabla f(\mathbf{X}_0)) = 0$), yielding zero directional preference for the linear assignment oracle ($\langle c\mathbf{1}, \mathbf{V}_1 - \mathbf{V}_2 \rangle = 0$). Standard solvers (such as FAQ) are forced to break ties arbitrarily, collapsing matching accuracy to $4.5\%$. Fast-WCS resolves this pathology through perturbed multi-start restarts ($85.5\%$ accuracy) and feature-asymmetric embeddings.

Fast-WCS: Six Analytical Innovations

Fast-WCS eliminates each limitation of prior continuous and combinatorial solvers through exact closed-form mathematics:

Lemma 1 · Complexity

Rank-One Dyadic Factorization

Proves $\mathbf{U} = \mathbf{r}\mathbf{r}^T$ with $\mathbf{r} = \mathbf{X}\mathbf{1}_N$, reducing co-matching memory from dense $\Theta(N^3)$ to $\mathcal{O}(MN + M^2)$ vector operations in strictly $\mathcal{O}(N^2)$ space.

Theorem 1 · Gradients

Exact Closed-Form Gradient in 3 GEMMs

Evaluates $\nabla_{\mathbf{X}} f(\mathbf{X}) = 4(\mathbf{R} \circ \hat{\mathbf{A}}_G)\mathbf{r}\mathbf{1}_N^T - 4\mathbf{R}\mathbf{X}\hat{\mathbf{A}}_H$ without polynomial approximations via three Level-3 BLAS matrix multiplications.

Theorem 2 · Optimization

Frank-Wolfe Duality Gap Certificate

Evaluates $g_t = \langle \nabla J_\zeta(\mathbf{X}_t), \mathbf{X}_t - \mathbf{Y}^* \rangle \ge 0$ at every step, providing an analytical certificate of first-order KKT stationarity and preventing unnecessary iterations.

Theorem 3 · Line Search

Quartic Line Search via Cardano's Formula

Solves the optimal 1D step size $\lambda^* = \arg\min_{\lambda \in [0, 1]} J_\zeta(\mathbf{X} - \lambda \mathbf{D})$ in closed-form $\mathcal{O}(1)$ time (< 0.25 μs) via Cardano's cubic resolvent, eliminating grid searches.

Theorem 4 · Cardinality

Exact Augmented Burkard Hungarian Oracle

Embeds the linear oracle into a square $(M+N-L) \times (M+N-L)$ assignment problem, guaranteeing strictly $\sum_{i,j} X^*_{ij} = L$ integer assignments with zero heuristic truncation error.

Combinatorial Refinement

Vectorized Level-3 BLAS 2-Opt Local Search

Simultaneously scores all candidate vertex exchanges and replacements via matrix-matrix multiplication in $\mathcal{O}(L^2 N)$ cost, bridging the continuous-to-discrete gap.
